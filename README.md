# Daseeki Armory

Equipment set manager for the Daseeki suite — ItemRack-style gear sets for WoW Classic Era.

## Features

- Per-character gear sets with an equip engine (`equip.lua`, `sets.lua`).
- Icon picker for custom set icons (`iconPicker.lua`, `iconData.lua`).
- Radial flyout widget for quick set switching (`flyout.lua`, `setFlyout.lua`, `widget.lua`).
- Keybind support (`keybind.lua`) and tooltips (`tooltip.lua`).
- Optional integration with ItemRack and OPie if installed (`opie.lua`).

## Requires

- Optional: [Daseeki Core](../Daseeki-Core) — adds the Armory options panel to the shared Daseeki options hub.
- Optional: [Daseeki Bags](../Daseeki-Bags) — for combined bag/set workflows.
- Optional: ItemRack, OPie — only used if already installed; not required.
